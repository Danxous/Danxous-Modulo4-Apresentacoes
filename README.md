# Módulo 4: Apresentações

Bem-vindo ao repositório dedicado às apresentações do Módulo 4 da disciplina de Engenharia de Software! Este espaço foi criado para organizar e compartilhar os materiais desenvolvidos durante o curso, promovendo o aprendizado colaborativo e a demonstração de conceitos avançados em engenharia de software.

Aqui você encontrará apresentações sobre tópicos como desenvolvimento ágil, arquitetura de software, testes e muito mais. Sinta-se à vontade para explorar, contribuir e aprender juntos!
